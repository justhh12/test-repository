# 🎯 Этап 1: Постановка задачи

## 📌 Бизнес-контекст

В телекоммуникационной индустрии **удержание клиента обходится в 5-7 раз дешевле**, чем привлечение нового. Поэтому прогнозирование оттока (Churn Prediction) — одна из ключевых задач для бизнеса.

## 🎯 Цель проекта

Разработать модель машинного обучения, которая **заблаговременно выявит клиентов с высокой вероятностью ухода**, чтобы отдел маркетинга мог предложить им персональные условия удержания (скидки, бонусы, улучшенные тарифы).

## 📊 Описание датасета

| Параметр | Значение |
|----------|----------|
| **Источник** | IBM Telco Customer Churn (Kaggle) |
| **Объём** | 7 043 клиента |
| **Признаков** | 21 (демография, услуги, платежи) |
| **Целевая переменная** | `Churn` (Yes/No) |
| **Период** | Данные за 2014-2015 гг. |

## 🧠 Тип задачи ML

**Бинарная классификация:**
- Класс `0` — клиент остался (No)
- Класс `1` — клиент ушёл (Yes)

## 📏 Выбор метрик

Для бизнес-задачи удержания клиентов критичны следующие метрики:

| Метрика | Приоритет | Обоснование |
|---------|-----------|-------------|
| **Recall** | 🔴 Высокий | Найти ВСЕХ уходящих клиентов. Лучше ошибиться и предложить скидку лояльному, чем потерять реального "беглеца" |
| **ROC-AUC** | 🟡 Средний | Общая способность модели разделять классы |
| **F1-score** | 🟡 Средний | Баланс между Precision и Recall |
| **Accuracy** | 🟢 Низкий | При дисбалансе классов может вводить в заблуждение |

## 💰 Ожидаемый бизнес-эффект

> Снижение оттока на **5%** при базе 100 000 клиентов и среднем чеке **$70/мес** = **$4.2 млн дополнительной выручки в год**
